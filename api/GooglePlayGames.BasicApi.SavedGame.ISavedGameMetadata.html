Filename

Returns the filename for this saved game. A saved game filename will only consist of non-URL reserved characters (i.e. a-z, A-Z, 0-9, or the symbols "-", ".", "_", or "~") and will between 1 and 100 characters in length (inclusive).

IsOpen

Returns true if this metadata can be used for operations related to raw file data (i.e. the binary data contained in the underlying file). Metadata returned by Open operations will be "Open". After an update to the file is committed or the metadata is used to resolve a conflict, the corresponding Metadata is closed, and IsOpen will return false.

bool IsOpen { get; }

Property Value

bool

true if this instance is open; otherwise, false.

LastModifiedTimestamp

A timestamp corresponding to the last modification to the underlying saved game. If the saved game is newly created, this value will correspond to the time the first Open occurred. Otherwise, this corresponds to time the last successful write occurred (either by CommitUpdate or Resolve methods).

DateTime LastModifiedTimestamp { get; }

Property Value

DateTime

The last modified timestamp.
