Class XRMODObjectPool

Namespace
Phantom.XRMOD.Core.Runtime

A runtime object pooling system for efficiently managing the lifecycle of GameObjects. Reduces GC allocations and performance spikes by recycling instances instead of repeatedly instantiating and destroying them.
