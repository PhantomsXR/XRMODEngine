ChooseMetadata(ISavedGameMetadata)

Resolves the conflict by choosing the passed metadata to be canonical. The passed metadata must be one of the two instances passed as parameters into ConflictCallback - this instance will be kept as the cannonical value in the cloud.

void ChooseMetadata(ISavedGameMetadata chosenMetadata)

Parameters

chosenMetadata ISavedGameMetadata

The chosen metadata. This metadata must be open. If it is not open, the invokation of NativeSavedGameClient.OpenWithManualConflictResolution that produced this ConflictResolver will immediately fail with BadInputError.

ResolveConflict(ISavedGameMetadata, SavedGameMetadataUpdate, byte[])

Resolves the conflict and updates the data.

void ResolveConflict(ISavedGameMetadata chosenMetadata, SavedGameMetadataUpdate metadataUpdate, byte[] updatedData)

Parameters

chosenMetadata ISavedGameMetadata

Metadata for the chosen version. This is either the original or unmerged metadata provided when the callback is invoked.

metadataUpdate SavedGameMetadataUpdate

Metadata update, same as when committing changes.

updatedData byte[]

Updated data to use when resolving the conflict.
