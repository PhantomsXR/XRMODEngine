Calibrate(VRIK, CalibrationData, Transform, Transform, Transform, Transform, Transform, Transform)

Calibrates VRIK to the specified trackers using CalibrationData from a previous calibration. Requires this character's bone orientations to match with the character's that was used in the previous calibration.

public static void Calibrate(VRIK ik, VRIKCalibrator.CalibrationData data, Transform headTracker, Transform bodyTracker = null, Transform leftHandTracker = null, Transform rightHandTracker = null, Transform leftFootTracker = null, Transform rightFootTracker = null)

Parameters

ik VRIK

Reference to the VRIK component.

data VRIKCalibrator.CalibrationData

Use calibration data from a previous calibration.

headTracker Transform

The HMD.

bodyTracker Transform

(Optional) A tracker placed anywhere on the body of the player, preferrably close to the pelvis, on the belt area.

leftHandTracker Transform

(Optional) A tracker or hand controller device placed anywhere on or in the player's left hand.

rightHandTracker Transform

(Optional) A tracker or hand controller device placed anywhere on or in the player's right hand.

leftFootTracker Transform

(Optional) A tracker placed anywhere on the ankle or toes of the player's left leg.

rightFootTracker Transform
