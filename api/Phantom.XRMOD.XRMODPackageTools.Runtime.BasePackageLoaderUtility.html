LoadAssetsFromPackageAsDictionary<T>(string, string[])

Asynchronously loads a batch of assets by names from a package and returns a name-to-asset map. Delegates to LoadAssetsFromPackage<T>(string, string[]) to ensure assets are loaded and ordered to match the input names, then builds a dictionary in that order.

public static Task<Dictionary<string, T>> LoadAssetsFromPackageAsDictionary<T>(string _projectName, string[] _assetNames) where T : UnityEngine.Object

Parameters

_projectName string

The project (package) name.

_assetNames string[]

The list of asset names to load, in the desired order.

Returns

Task<Dictionary<string, T>>

A dictionary mapping asset name to asset instance. The insertion order of the dictionary follows the order of _assetNames. Enumeration over the dictionary will reflect that order.

Type Parameters

T

The type of the assets to load (must inherit from UnityEngine.Object).

Exceptions

ArgumentNullException

Thrown if _assetNames is null.

IndexOutOfRangeException

Propagated if any requested asset is missing.

LoadBundleFromUrl<T>(string, int, string, Hash128, uint, Action<float>, Action<string>)

Asynchronously loads a specific asset from an asset bundle downloaded from a URL string. Supports caching and progress reporting.

public static Task<T> LoadBundleFromUrl<T>(string _uri, int _timeout, string _wannaLoadAssetsName, Hash128 _hash128, uint _crc, Action<float> _progressAction, Action<string> _failedAction) where T : UnityEngine.Object

Parameters

_uri string

The URI string of the asset bundle to download.

_timeout int

The timeout duration for the web request in seconds.

_wannaLoadAssetsName string

The name of the asset to load from the bundle.

_hash128 Hash128

A version hash for caching. If it doesn't match, the bundle will be re-downloaded.

_crc uint

A checksum for data integrity. If zero, CRC checking is skipped.

_progressAction Action<float>

Callback invoked to report download progress (0.0 to 1.0).

_failedAction Action<string>

Callback invoked if asset loading fails, providing an error message.

Returns

Task<T>

A Task representing the asynchronous operation, yielding the loaded asset.

Type Parameters

T

The type of the asset to load (must inherit from UnityEngine.Object).
