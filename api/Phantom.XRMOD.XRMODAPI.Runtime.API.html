ARRaycast(Vector3, TrackableTypeEnum, Action<Pose>)

Casts a ray from a point in screen space against trackables (e.g., detected planes). This only works in Handheld AR.

public void ARRaycast(Vector3 _inputPosition, TrackableTypeEnum _trackableType = TrackableTypeEnum.PlaneWithinPolygon, Action<Pose> _callback = null)

Parameters

_inputPosition Vector3

The input screen point for the raycast.

_trackableType TrackableTypeEnum

The type of trackables to hit. See TrackableTypeEnum.

_callback Action<Pose>

A callback action that is invoked with the Pose result of the raycast.

Examples

api.ARRaycast(Input.mousePosition, TrackableTypeEnum.PlaneWithinPolygon, (pose) => {
    Instantiate(prefab, pose.position, pose.rotation);
});

ChangeSpaceType(SpaceType, Vector3?, Vector3?, string[], BoundResizeMode)

Changes the current experience space type.

public void ChangeSpaceType(SpaceType _spaceType, Vector3? _dimensions = null, Vector3? _boundPosition = null, string[] _cullingMask = null, BoundResizeMode _boundResizeMode = BoundResizeMode.None)

Parameters

_spaceType SpaceType

The new space type. See SpaceType.

_dimensions Vector3?

Optional: The dimensions for the new space. Defaults to Vector3.one.

_boundPosition Vector3?

Optional: The bound position for the new space. Defaults to Vector3.up * 0.5f.

_cullingMask string[]

Optional: An array of layer names to be used for culling. If null, no culling mask is applied.

_boundResizeMode BoundResizeMode

Optional: The bound resize mode. Defaults to None.
