SpawnNetworkGameObject(GameObject, Vector3, Quaternion, Transform, bool, Action<GameObject>)

Spawns a network object for all connected clients. This method should only be called on the server or host.

public GameObject SpawnNetworkGameObject(GameObject _networkPrefab, Vector3 _position, Quaternion _rotation, Transform _parent = null, bool _destroyWithScene = false, Action<GameObject> _onBeforeSpawned = null)

Parameters

_networkPrefab GameObject

The GameObject prefab to spawn, which must have a NetworkObject component.

_position Vector3

The world position to spawn the object at.

_rotation Quaternion

The world rotation to spawn the object with.

_parent Transform

The parent Transform(NetworkObject have) for the spawned object. Defaults to null (no parent).

_destroyWithScene bool

If true, the object will be destroyed when the scene changes. Defaults to false.

_onBeforeSpawned Action<GameObject>

An optional action to invoke on the instantiated GameObject before it is spawned over the network.

Returns

GameObject

The spawned GameObject, or null if the prefab does not have a NetworkObject component or instantiation fails.
