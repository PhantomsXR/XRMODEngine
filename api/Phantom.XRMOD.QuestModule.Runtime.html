Namespace Phantom.XRMOD.QuestModule.Runtime

Classes

ArchitectureComponentsModel

Holds references to the essential architectural components of the Quest XR rig.

This model is responsible for locating and caching references to cameras, managers (AR, Input, Occlusion), providers (Locomotion, Turn, Climb), and controller transforms. It acts as a central registry for accessing these components.

AutoRegisterModule

Automatically registers the Meta Quest module when running on a Quest device.

BaseMetaQuestFeatureDecorator

Base abstract decorator for Meta Quest features.

Provides common functionality for registering feature decorators at runtime. Implementations should override StartAlgorithm(), PauseAlgorithm(), and StopAlgorithm().

BuildMetaQuestInteracterSwitcherFeatureCommand

Command to build and initialize the Meta Quest Interactor Switcher feature.

This command creates an instance of MetaQuestInteracterSwitherDecorator to handle interaction switching.

BuildMetaQuestLocomotionFeatureCommand

Command to build and initialize the Meta Quest Locomotion feature.

This command creates an instance of MetaQuestLocomotionFeatureDecorator to handle locomotion logic.

BuildMetaQuestMRFeatureCommand

Command to build and initialize the Meta Quest Mixed Reality feature.

This command creates an instance of MetaQuestMRFeatureDecorator to enable mixed reality capabilities like passthrough.

BuildMetaQuestMeshFeatureCommand

Command to build and initialize the Meta Quest Meshing feature.

This command handles loading the mesh visualizer (either default or custom) and initializing the MetaQuestMeshingDecorator.

BuildMetaQuestOcclusionFeatureCommand

Command to build and initialize the Meta Quest Occlusion feature.

This command creates an instance of MetaQuestOcclusionDecorator to handle environmental occlusion.

BuildMetaQuestSceneCaptureCommand

Command to build and initialize the Meta Quest Scene Capture feature.

This command creates an instance of MetaQuestSceneCaptureDecorator to handle scene capture functionality.

BuildXRAlgorithmLifeControllerCommand

Manages the lifecycle of XR algorithms on the Quest platform.

Listens for ARAlgorithmLifeCTRL notifications and controls the state (Start, Pause, Stop) of various algorithms such as Meshing and Passthrough.

MetaQuestBoundingBoxesDecorator

Feature decorator for handling AR Bounding Boxes on Meta Quest.

Initializes the ARBoundingBoxManager and listens for trackable changes, notifying the system via ActionNotificationCenter.

MetaQuestInteracterSwitherDecorator

Feature decorator for switching between different interaction inputs on Meta Quest.

Listens for input switch notifications and activates/deactivates corresponding controllers (Hands, XR Controllers, etc.).

MetaQuestLocomotionFeatureDecorator

Feature decorator for enabling/disabling locomotion features on Meta Quest.

Controls the activation of teleport interactors, character controllers, and locomotion providers.

MetaQuestMRFeatureDecorator

Feature decorator for Meta Quest Mixed Reality (Passthrough).

Controls the camera background to enable or disable passthrough mode.

MetaQuestMeshingDecorator

Feature decorator for Meta Quest Meshing.

Manages the ARMeshManager and dispatches notifications when meshes are added, updated, or removed.

MetaQuestModule

The main module class for Meta Quest support in XR-MOD.

This class implements the IModule interface and is responsible for managing the lifecycle of Quest-specific features such as Mixed Reality, Occlusion, and Meshing. It listens for configuration changes and initializes the appropriate systems.

MetaQuestOcclusionDecorator

Feature decorator for Meta Quest Occlusion.

Configures AROcclusionManager settings such as environment depth and human segmentation based on the runtime configuration.

MetaQuestSceneCaptureDecorator

Feature decorator for triggering Meta Quest Scene Capture (Spatial Setup).

Listens for a capture environment notification to request scene capture from the system.

PassthroughCameraDebugger

Utility class for handling debug logging with varied levels of verbosity.

PassthroughCameraPermissions

Manages permission requests for Passthrough Camera access on Meta Quest.

PassthroughCameraUtils

Utility class for interacting with the Meta Quest Passthrough Camera API.

Provides methods to access camera intrinsics, poses, and frames via Android Java calls.

WebCamTextureManager

Manages the creation and lifecycle of a WebCamTexture for a specific passthrough camera eye.

Handles permission checks and initializes the webcam texture with the requested resolution.

XRConfiguresModel

Configuration model for Meta Quest specific features.

Contains settings for mesh visualization, occlusion preferences, depth modes, and hand removal.

XRControllerVisualizerGroup

Represents a group of visualizers for XR controllers on a specific platform.

XRControllerVisualizerManager

Manages the activation of controller visualizers based on the current platform.

XRRuntimeContextDataModel

Runtime data model for the Quest module.

Stores the state of the AR session, availability, visualizers, feature decorators, and other runtime context information.
