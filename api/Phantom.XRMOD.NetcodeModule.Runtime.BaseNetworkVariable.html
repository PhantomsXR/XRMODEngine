Remarks

This abstract class provides common configuration for network variables:

  • Read/Write permissions
  • Change event subscriptions
  • Unique key identification

All network variable components require an XRMODNetworkBehaviour on the same GameObject. Derived classes implement specific synchronization logic for different data types.
